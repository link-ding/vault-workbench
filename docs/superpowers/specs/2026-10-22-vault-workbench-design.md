## 推荐操作流程

1. 双击“启动 VAULT 工作台”，自动打开本机浏览器。
2. 首页显示模型库路径、实际扫描数量和资料状态；提供更改路径及重新扫描。
3. 选择“抽屉”“翻盖箱”或“配件补打”。
4. 使用中文选项选择型号、宽度系列、深度、外壳高度及数量，只显示本地存在的组合。
5. 选择适用的顶盖、内部布局、把手、锁定方式和安装配件。每个选项提供中文解释和可用的官方示意图。
6. 支持把多个需求加入同一打印计划，也支持选择同尺寸外壳中的多抽屉组合；总高度和兼容规则必须通过校验。
7. 预览零件表：中文名称、英文文件名、打印份数、原文件路径、用途、是否选配、支撑/材料说明及证据来源。
8. 点击“整理并打包”，生成 ZIP 和本地导出记录，允许打开导出文件夹。

页面采用选择区、配置说明区、清单区的结构。首版专注配置和文件导出，不把自由拖拽堆塔、自动切片或打印机控制作为交付前提。

## 文件选择与数量规则

### 精确索引

扫描真实路径建立目录，不用宽泛关键词搜索直接决定导出结果。目录可能有大小写、空格、单复数、拼写和上标符号差异，例如 `Roof`/`Roofs`、`4F`/`4f`、`L²`、`Heawyweight`；索引需要兼容这些差异，导出时保留真实文件名及来源。

型号目录仅包含部分部件。面板可能位于家族公共目录；滑轨、弹簧、锁和铰链等位于 Universal。每条装配配方必须列全其依赖。

### 按配置生成配方

- 抽屉包含外壳、内抽、对应面板、锁组件、弹簧、滑轨和限位件；顶盖、提手、标签、连接扣及齿条按用途和条件加入。
- 翻盖箱包含箱体、顶盖、对应面板、锁组件及销、上下铰链和轴；分隔片和内部结构随适用型号选择。
- 整块和分体顶盖互斥；选择分体时同时匹配连接件。没有分体文件时不伪造该选项。
- 改装配件按实际存在的宽度、高度及安装条件匹配；轮胎单独标注 TPU。
- L²/XL² 等特殊外壳单独建立规则。首轮对全部文件完成索引；配方未验证的组合明确显示“规则待核对”，允许浏览文件，禁止一键导出“完整套件”。

打印数量必须区分“一个物体”和“一个 STL 文件内的一组物体”。例如文件名已经写明整套销的文件，不能再按销的总个数重复乘份数。需要结合装配图和模型几何确认。

### 证据与冲突

每条关键规则记录来源文档、页码和核对状态。说明书未明确而由模型结构判断的内容标注为结构核对或推断，不能标为官方要求。

已发现的差异：主说明书第 3 页给出抽屉每层 4 颗 M4×14，第 18 页又注明 1F 为 4 颗、2F/4F 为 6 颗；官网某些页面的示例也与本地资料存在不同。必须按实际文件和细分图核对，不能把总表或示意图当作所有型号的通用数量。

抽屉装配第 4 页将齿条列为条件选配：额外锁定力或 2F/4F 外壳中安装多个内抽时使用。因此不能对所有普通单抽屉都列为必打，也不能在多抽屉配置中遗漏。

## ZIP 内容

- `STL/`：按主体、机构、选配件及耗材类别组织，保留英文原文件名。
- `打印清单.csv`：中文用途、文件、数量、来源和注意事项，Excel 可直接打开。
- `打印说明.txt`：选中的配置、逐项打印数量、材料与支撑提示、装配阅读指引。
- `五金清单.csv`：只列与本次配置有关的五金；冲突未解决时明确标注，不编造数量。
- `manifest.json`：原始相对路径、配置、数量、文件大小和 SHA-256，便于追溯和复核。

同一 STL 在包内只存一次，清单累计打印份数。只有用户选中的配件进入包。每次导出使用独立目录，不覆盖历史导出。

## 实现边界

建议用本地 Python 服务完成目录索引、规则解析、ZIP 和历史记录，浏览器界面处理中文选择及预览。静态资源随项目保存，安装后离线使用，不需要 AI API 或付费服务。

服务仅监听本机回环地址。文件请求使用索引 ID，路径必须属于已配置的模型库；只读取原始模型，导出内容写入独立输出目录。规则库、文件扫描、清单计算、打包和界面各自独立。

模型更新后重新扫描；出现缺文件、多候选、依赖规则未验证或尺寸不兼容时，显示具体原因并阻止完整套件导出，不选择“最像”的文件凑数。

尺寸展示区分装配尺寸、STL 几何包围盒和所需打印空间；不把箱体外尺寸当作打印机适配依据。没有可靠的切片结果时不显示虚构的耗时或耗材重量。

## 验收方式

1. 扫描当前库得到 723 个 STL，且分类数与调研一致。
2. 对小型抽屉、高抽屉、多抽屉、翻盖箱和分体顶盖等代表配置核对说明书及实际模型。
3. 对开放的全部组合执行依赖完整性校验；不存在的组合不可选择。
4. 真实导出至少一个抽屉和一个翻盖箱 ZIP，解包核对路径、份数、文件哈希及清单。
5. 检查缺文件、名称差异、重复候选、非法路径及重复导出，确保错误有解释、源文件不被改动。
6. 浏览器检查完整的中文选择、添加计划、预览、导出和历史记录流程。
