# 实现计划

已获用户确认，直接推进实现，不增加审批环节。当前环境未安装 brainstorming 引用的 writing-plans 技能；使用本计划记录等价的实施步骤。

1. 建立标准库 Python 本地服务、实际文件索引与精确路径选择。
2. 用说明书及 STL 网格核实一份文件内的零件数，编写抽屉、翻盖箱及选配件配方；歧义组合禁用完整套件导出。
3. 实现打印计划合并、清单、SHA-256 校验、异步 ZIP、历史记录和独立补打。
4. 编写中文浏览器界面，加入官方图片、零件预览、手册阅读和模型库搜索；离线资源随项目提供。
5. 编写 Windows 双击启动入口，选择可用的 Python 3，启动后自动打开工作台。
6. 验证所有开放配方依赖、组合条件及路径边界；真实导出并解包核对抽屉、翻盖箱测试包。
7. 浏览器完成配置、补打、计划、打包、历史及手册阅读的验收，提供启动入口和使用说明。

技术分工：`catalog.py` 负责索引；`recipes.py` 负责配套规则；`exporter.py` 负责清单与打包；`server.py` 负责本地 HTTP；`web/` 负责界面；`tests/` 检查装配与导出契约。
